# SauceDemo Login & Cart Test

An automated test suite for validating the login functionality and cart addition workflow on [SauceDemo](https://www.saucedemo.com/), a demo e-commerce website for testing purposes.

## 🎯 Overview

This test automates the following user journey:

1. Navigate to the SauceDemo login page
2. Enter valid credentials
3. Verify successful login
4. Add a product to the shopping cart
5. Navigate to the cart page
6. Validate the cart URL

## 📦 Prerequisites

Before running this test, ensure you have the following installed:

| Software | Version | Purpose |
|----------|---------|---------|
| Python | 3.7+ | Test execution environment |
| Chrome Browser | Latest | Browser for automation |
| ChromeDriver | Matching Chrome version | WebDriver for Chrome |
